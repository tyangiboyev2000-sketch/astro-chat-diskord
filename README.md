# Global Chat Hub

"Create a simplified, highly readable Discord-style web application with multi-language support (Uzbek, Russian, and English).

Add a language switcher dropdown at the top-right corner with flags or language codes (UZ, RU, EN).

Build a clean 3-column layout:

Left sidebar: Server icons/navigation.

Middle sidebar: Channels list (Text channels like #general / #umumiy, #announcements / #elonlar, and Voice channels).

Main chat area: Clean chat log and a message input bar at the bottom.

Translate all UI labels (channel headers, placeholder texts, settings, buttons) based on the selected language."
